📂 How to Extract and Set Up

Windows has a built-in way to open ZIP files. Here's how:

  1. Locate the ZIP file – open your File Explorer and go to your Downloads folder.
  2. Double-click the ZIP file – this opens it like a folder.
  3. Click "Extract All" – this button appears at the top of the window. Follow the prompts, and keep the default extraction location (usually another folder in Downloads).
  4. Open the extracted folder – you'll now see a folder called atlas-main. This is your atlas application folder.

Now you're ready to launch. Inside the folder, look for the atlas executable file. It might be named atlas.exe or simply atlas, depending on the version. Double-click it to run atlas. The app will open in your web browser at http://localhost:3000.
